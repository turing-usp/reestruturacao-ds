# Reestruturação da Área de Data Science — Turing USP

## Sobre o projeto

Este repositório faz parte do projeto de **reestruturação da área de Data Science do Turing USP**.

O objetivo é construir uma formação prática e colaborativa em Data Science, promovendo o aprofundamento dos conhecimentos, a aplicação prática dos conteúdos estudados e a troca de experiências entre os participantes.

Ao longo do projeto, serão desenvolvidos **notebooks, estudos e projetos práticos**, que serão documentados e organizados neste repositório.

## Objetivos:

- Aprofundar conhecimentos em Data Science;
- Aplicar os conteúdos estudados na prática;
- Promover a colaboração e a troca de conhecimentos;
- Desenvolver projetos em conjunto;
- Construir um portfólio de projetos em Data Science.
